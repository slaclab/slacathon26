# SLACATHON Client Examples

Example clients for interacting with the SLACATHON API.

- `gp_optimizer.py`: Gaussian Process optimizer using sklearn
- `xopt_optimizer.py`: Xopt-based Bayesian optimizer
- `usage.py`: Simple validation client
- `optimize_usage.py`, `optimize_xopt_usage.py`: Full optimization loops with parameter fixing

These are **not** part of the server package. They consume the running API.

See top-level README for server setup.
